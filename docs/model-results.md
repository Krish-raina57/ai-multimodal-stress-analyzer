# Model results

The following values are reproduced from the original presentation script.

| Modality | Model | Reported accuracy |
|---|---|---:|
| Text | LSTM | 88% |
| Audio | CNN | 44% |
| Facial expression | CNN | 52% |

## Interpretation
The presentation identifies text as the strongest individual modality in the reported experiments. It describes the audio and facial-expression models as more challenging due to emotion-label overlap, class imbalance, lighting variation, pose, and occlusion.

## Critical evaluation caveat
The original presentation does not provide confusion matrices, per-class metrics, dataset split details, or saved evaluation logs. These numbers should therefore be labelled **reported presentation results**, not independently reproduced benchmark results.

No final numerical accuracy for the fused model was reported.
