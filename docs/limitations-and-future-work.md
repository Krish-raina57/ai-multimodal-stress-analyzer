# Limitations and future work

## Known limitations from the project presentation
- Separate datasets were used for text, audio, and facial-expression branches.
- The three modalities were not yet aligned to the same underlying stress events.
- Final fusion evaluation was pending.
- The audio dataset was described as limited.
- Dataset imbalance and CNN overfitting were identified as challenges.

## Future work proposed by the team
1. Build or obtain a synchronized dataset with text, audio, and face data for the same samples.
2. Evaluate late fusion on a properly aligned test set.
3. Compare simple averaging with weighted fusion.
4. Develop a real-time application using a webcam and microphone.

## Responsible-use note
Stress inference from text, voice, or facial expression is uncertain and context-dependent. This academic prototype should not be used for diagnosis, employment decisions, surveillance, or other high-stakes judgments.
